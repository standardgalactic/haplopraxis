   CAPTION: Windows Executable File

   [89][64px-Windows_11_executable.svg.png]
   [90]Filename extension
   .exe
   [91]Internet media type
   application/vnd.microsoft.portable-executable
   [92]Magic number 0x4d 0x5a
   Developed by [93]Microsoft
   Type of format Executable file
   [94]Container for [95]MZ, [96]NE, LX, [97]LE, [98]PE, PE32+, W3, W4,
   DL, MP, P2, P3

   [99]Open format? No

   For [100]Microsoft [101]Windows, [102]OS/2, and [103]DOS, .exe is the
   [104]filename extension that denotes a file as being [105]executable –
   a [106]computer program – containing an [107]entry point.^[108][1]

   In addition to being executable (adjective) such a file is often called
   an executable (noun) which is sometimes abbreviated as EXE.

File formats

   [[109]edit]

   The [110]file format of an EXE file varies by operating system version.

   An operating system cannot use an EXE file unless it is formatted for
   it. Note that some formats support multiple operating systems.

DOS

   [[111]edit]

   16-bit [112]DOS MZ executable (MZ)
          The original DOS executable file format. These formats can be
          identified by the letters "MZ" at the beginning of the file in
          ASCII. Later formats may contain an MZ [113]DOS stub
          header.^[114][2]

   16-bit [115]New Executable (NE)
          Introduced with the multitasking [116]MS-DOS 4.0 and also used
          by 16-bit [117]OS/2 and Windows, NE can be identified by the
          "NE" in ASCII.

OS/2

   [[118]edit]

   32-bit Linear Executable (LX)
          Introduced with OS/2 2.0, these can be identified by the "LX" in
          ASCII. These can only be run by OS/2 2.0 and higher.^[119][3]

   Mixed 16/32-bit Linear Executable (LE)
          Introduced with OS/2 2.0, these can be identified by the "LE" in
          ASCII. [120]VxD drivers on [121]Windows 3.x, [122]OS/2, and
          [123]Windows 9x also use LE format.

Windows

   [[124]edit]

   32-bit [125]Portable Executable (PE)
          Introduced with [126]Windows NT, they are [127]fat binaries
          consisting of a DOS-specific and a Windows-specific part. The
          DOS-specific part (dubbed [128]DOS stub) is a legitimate 16-bit
          DOS program. Microsoft C++ linker, by default, uses a minimal
          DOS stub that prints the following message: "This program cannot
          be run in DOS mode."^[129][2]^[130][4]^[131][5] Windows ignores
          the DOS stub and executes the Windows-specific portion that
          starts with the "PE\0\0" ASCII sequence (letters "PE" and two
          null bytes).^[132][2] With some linkers, it is possible to
          specify a custom DOS stub.^[133][2]^[134][4]^[135][6] Indeed,
          there are a few dual programs, such as [136]regedit in
          [137]Windows 95^[138][7] and old versions of [139]WinZIP self
          extractors.

   64-bit Portable Executable (PE32+)
          Introduced by 64-bit versions of Windows, this is a PE file with
          wider fields. In most cases, code can be written to simply work
          as either a 32 or 64-bit PE file.^[140][8] This file also
          includes a DOS stub.^[141][6]

Other

   [[142]edit]

   There are other EXE formats, including but not limited to W3 (a
   collection of LE files, only used in WIN386.EXE), W4 (a compressed
   collection of LE files, only used in VMM32.VXD), DL, MP, P2, P3 (last
   three used by [143]Phar Lap extenders).^[144][9]
