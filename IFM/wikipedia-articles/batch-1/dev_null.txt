   From Wikipedia, the free encyclopedia
   (Redirected from [83]/dev/null)
   Device file that discards all data written to it
   For the electropop band, see [84]Null Device.
   Not to be confused with [85]/dev/zero.

   In some [86]operating systems, the null device is a [87]device file
   that discards all data written to it but reports that the write
   operation succeeded. This device is called /dev/null on [88]Unix and
   [89]Unix-like systems, NUL: (see [90]TOPS-20) or NUL on [91]CP/M and
   [92]DOS (internally \DEV\NUL), nul on [93]OS/2 and newer [94]Windows
   systems^[95][1] (internally \Device\Null on [96]Windows NT), NIL: on
   [97]Amiga operating systems,^[98][2] and NL: on [99]OpenVMS.^[100][3]
   In [101]Windows Powershell, the equivalent is $null.^[102][4] It
   provides no data to any [103]process that reads from it, yielding
   [104]EOF immediately.^[105][5] In IBM operating systems [106]DOS/360
   and successors^[107][a] and also in [108]OS/360 and successors^[109][b]
   such files would be assigned in [110]JCL to DD DUMMY.

   In programmer jargon, especially Unix jargon, it may also be called the
   [111]bit bucket^[112][6] or [113]black hole.

History

   [[114]edit]

   /dev/null is described as an empty regular file in [115]Version 4
   Unix.^[116][7]

   The [117]Version 5 Unix manual describes a
   /dev/null device with modern semantics.^[118][8]

Usage

   [[119]edit]

   The null device is typically used for disposing of unwanted output
   [120]streams of a process, or as a convenient empty [121]file for input
   streams. This is usually done by [122]redirection. For example, tar -c
   -f /dev/null "example directory" can be used to dry-run the [123]TAR
   file archiving utility to see if any errors would occur but without
   writing any file.

   The /dev/null device is a [124]special file, not a [125]directory, so
   one cannot move a whole file or directory into it with the Unix [126]mv
   command.

References in computer culture

   [[127]edit]

   This entity is a common inspiration for technical [128]jargon
   expressions and [129]metaphors by Unix programmers, e.g. "please send
   complaints to /dev/null", "my mail got archived in /dev/null", and
   "redirect to /dev/null"—being jocular ways of saying, respectively:
   "don't bother sending complaints", "my mail was deleted", and "go
   away". The [130]iPhone Dev Team commonly uses the phrase "send
   donations to /dev/null", meaning they do not accept donations.^[131][9]
   The fictitious person name "Dave (or Devin) Null" is sometimes
   similarly used (e.g., "send complaints to Dave Null").^[132][10] In
   1996, [133]Dev Null was an animated [134]virtual reality character
   created by [135]Leo Laporte for MSNBC's computer and technology TV
   series [136]The Site. Dev/null is also the name of a vampire hacker in
   the computer game [137]Vampire: The Masquerade – Redemption. A 2002
   advertisement for the Titanium [138]PowerBook G4 reads "Sends other
   UNIX boxes to /dev/null."^[139][11]

   The null device is also a favorite subject of technical
   jokes,^[140][12] such as warning users that the system's /dev/null is
   already 98% full. The 1995 [141]April Fool's issue of the [142]German
   magazine [143]c't reported on an enhanced /dev/null [144]chip that
   would [145]efficiently dispose of the incoming data by converting it to
   a flicker on an internal glowing [146]LED.

   Dev/Null is also the name of an electronic dance music producer and
   jungle DJ.^[147][13]
