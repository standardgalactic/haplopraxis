   CAPTION: mobi

   [98][180px-DotMobi.png]
   Introduced 2005; 20 years ago (2005)
   [99]TLD type [100]Generic top-level domain
   Status Active
   [101]Registry dotMobi (subsidiary of [102]Afilias)
   Sponsor None
   Intended use Mobile content providers
   Actual use Mobile products and services websites
   Registration restrictions None. Adherence to [103]mobile-first style
   guidelines recommended.
   Structure Registrations are conducted at second level.
   Documents [104]ICANN Registry Agreement
   Dispute policies [105]UDRP
   [106]DNSSEC Yes
   Registry website [107]dotMobi.mobi

   The domain name mobi is a [108]generic top-level domain (gTLD) in the
   [109]Domain Name System (DNS) of the [110]Internet. The name is short
   for mobile.

   The domain was approved by [111]ICANN on 11 July 2005, and is managed
   by the mTLD global registry. It was originally financially backed and
   sponsored by [112]Google, [113]Microsoft, [114]Nokia, [115]Samsung,
   [116]Ericsson, [117]Vodafone, [118]T-Mobile, [119]Telefónica Móviles,
   [120]Telecom Italia Mobile, [121]Orascom Telecom, [122]GSM Association,
   [123]Hutchison Whampoa, [124]Syniverse Technologies, and [125]Visa,
   with an executive from each company serving on mTLD's board of
   directors.^[126][1] In February 2010, [127]Afilias acquired mTLD
   Top-Level Domain Ltd. (known publicly as "dotMobi").^[128][2] In March
   2017, .mobi became an unsponsored generic top-level domain, using the
   same terms offered to [129]new gTLDs.^[130][3]

Operation

   [[131]edit]

   DotMobi domain names have been available for registration by the public
   since 26 September 2006.

   dotMobi engaged with the [132]W3C Mobile Web Initiative (MWI) to help
   formulate the MWI Best Practices for mobile content. The practices
   outlined a number of ways to achieve good user experiences on mobile
   Web-enabled devices, and recognized several methods of implementing
   these practices.

   mTLD has released a free testing tool called Ready.mobi (later
   mobiForge) to analyze the mobile readiness of websites. It does a free
   page analysis and gives a .mobi Ready score from 1 to 5. This report
   tests the mobile-readiness of the site using dotMobi's recommended best
   practices.

   dotMobi does not itself mandate any particular technology, but does
   recommends that .mobi sites produce user experiences consistent with
   their guidelines and specifically optimized for mobile phones.

   By 2024, the old authoritative [133]WHOIS domain for .mobi had been
   allowed to expire, which created a vulnerability that included allowing
   for the creation of fraudulent [134]digital certificates.^[135][4]

mobiForge

   [[136]edit]

   "mobiForge" is a [137]mobile development and [138]design resource site
   run dotMobi. mobiForge functions both as a platform to announce product
   updates to the [139]developer community and [140]discussion forums for
   each of dotMobi's products and services. mobiForge was launched in
   November 2006 as dev.mobi. It was announced at the [141]Mobile 2.0
   Conference in [142]San Francisco, along with the launch of ready.mobi.
   dev.mobi underwent a major [143]redesign in September 2008 and was
   rebranded as mobiForge and moved to mobiForge.com

Reception

   [[144]edit]

   Originally dotMobi focused on promoting the creation of two separate
   device-dependent [145]World Wide Webs, one desktop-based and the other
   mobile-based. Because of this, [146]Tim-Berners Lee brought up concerns
   of excess Internet content redundancy.^[147][5]

   Providing content tailored to particular devices can be done by other
   means than a specific TLD, such as using hostnames within an existing
   domain, [148]HTTP [149]content negotiation, [150]cascading style
   sheets, or other forms of adaptation. The popularization of
   [151]responsive web design has caused the domain name to be relocated
   for use on mobile services and [152]mobile apps websites.
