   From Wikipedia, the free encyclopedia
   Traditional first example of a computer programming language
   "Hello, World" and "Helloworld" redirect here. For other uses, see
   [127]Hello World (disambiguation).

   A "Hello, World!" program is usually a simple [128]computer program
   that emits (or displays) to the screen (often the [129]console) a
   message similar to "Hello, World!". A small piece of code in most
   [130]general-purpose programming languages, this program is used to
   illustrate a language's basic [131]syntax. Such program is often the
   first written by a student of a new programming language,^[132][1] but
   such a program can also be used as a [133]sanity check to ensure that
   the [134]computer software intended to [135]compile or run [136]source
   code is correctly installed, and that its operator understands how to
   use it.

History

   [[137]edit]
   [138][220px-Hello_World_Brian_Kernighan_1978.jpg] "Hello, World!"
   program handwritten in the [139]C language and signed by [140]Brian
   Kernighan (1978)

   While small test programs have existed since the development of
   programmable [141]computers, the tradition of using the phrase "Hello,
   World!" as a test message was influenced by an example program in the
   1978 book [142]The C Programming Language,^[143][2] with likely earlier
   use in [144]BCPL. The example program from the book prints "hello,
   world", and was inherited from a 1974 [145]Bell Laboratories internal
   memorandum by [146]Brian Kernighan, Programming in C: A
   Tutorial:^[147][3]
main( ) {
        printf("hello, world");
}

   In the above example, the main( ) [148]function defines where the
   program [149]should start executing. The function body consists of a
   single [150]statement, a call to the printf() function, which stands
   for "print formatted"; it outputs to the [151]console whatever is
   passed to it as the [152]parameter, in this case the [153]string
   "hello, world".

   The C-language version was preceded by Kernighan's own 1972 A Tutorial
   Introduction to the Language [154]B,^[155][4] where the first known
   version of the program is found in an example used to illustrate
   external variables:
main( ) {
    extrn a, b, c;
    putchar(a); putchar(b); putchar(c); putchar('!*n');
}

a 'hell';
b 'o, w';
c 'orld';

   The program above prints hello, world! on the terminal, including a
   [156]newline character. The phrase is divided into multiple variables
   because in B a character constant is limited to four [157]ASCII
   characters. The previous example in the tutorial printed hi! on the
   terminal, and the phrase hello, world! was introduced as a slightly
   longer greeting that required several character constants for its
   expression.

   The [158]Jargon File reports that "hello, world" instead originated in
   1967 with the language [159]BCPL.^[160][5] Outside computing, use of
   the exact phrase began over a decade prior; it was the [161]catchphrase
   of New York radio disc jockey [162]William B. Williams beginning in the
   1950s.^[163][6]

Variations

   [[164]edit]
   [165][220px-PSP-Homebrew.jpeg] A "Hello, World!" program running on
   Sony's [166]PlayStation Portable as a [167]proof of concept

   "Hello, World!" programs vary in complexity between different
   languages. In some languages, particularly [168]scripting languages,
   the "Hello, World!" program can be written as one statement, while in
   others (more so many [169]low-level languages) many more statements can
   be required. For example, in [170]Python, to print the string Hello,
   World! followed by a newline, one only needs to write print("Hello,
   World!"). In contrast, the equivalent code in [171]C++^[172][7]
   requires the import of the [173]input/output (I/O) [174]software
   library, the manual declaration of an [175]entry point, and the
   explicit instruction that the output string should be sent to the
   [176]standard output stream.
   [177][220px-CNC_Hello_World.jpg] Computer [178]numerical control (CNC)
   machining test in [179]poly(methyl methacrylate) (Perspex).

   The phrase "Hello, World!" has seen various deviations in casing and
   punctuation, such as the capitalization of the leading H and W, and the
   presence of the comma or exclamation mark. Some devices limit the
   format to specific variations, such as all-capitalized versions on
   systems that support only capital letters, while some [180]esoteric
   programming languages may have to print a slightly modified string. For
   example, the first non-trivial [181]Malbolge program printed "HEllO
   WORld", this having been determined to be [182]good
   enough.^[183][8]^[[184]unreliable source?] Other human languages have
   been used as the output; for example, a tutorial for the [185]Go
   language emitted both English and Chinese or Japanese characters,
   demonstrating the language's built-in [186]Unicode support.^[187][9]
   Another notable example is the [188]Rust language, whose management
   system automatically inserts a "Hello, World" program when creating new
   projects.
   [189][220px-HelloWorld_Maktivism_ComputerProgramming_LEDs.jpg] A
   "Hello, World!" message being displayed through long-exposure
   [190]light painting with a moving strip of [191]light-emitting diodes
   (LEDs)

   Some languages change the function of the "Hello, World!" program while
   maintaining the spirit of demonstrating a simple example.
   [192]Functional programming languages, such as [193]Lisp, [194]ML, and
   [195]Haskell, tend to substitute a [196]factorial program for "Hello,
   World!", as functional programming emphasizes recursive techniques,
   whereas the original examples emphasize I/O, which violates the spirit
   of pure functional programming by producing [197]side effects.
   Languages otherwise able to print "Hello, World!" ([198]assembly
   language, [199]C, [200]VHDL) may also be used in [201]embedded systems,
   where text output is either difficult (requiring added components or
   communication with another computer) or nonexistent. For devices such
   as [202]microcontrollers, [203]field-programmable gate arrays, and
   [204]complex programmable logic devices (CPLDs), "Hello, World!" may
   thus be substituted with a blinking [205]light-emitting diode (LED),
   which demonstrates timing and interaction between
   components.^[206][10]^[207][11]^[208][12]^[209][13]^[210][14]

   The [211]Debian and [212]Ubuntu [213]Linux distributions provide the
   "Hello, World!" program through their [214]software package manager
   systems, which can be invoked with the command hello. It serves as a
   [215]sanity check and a simple example of installing a software
   package. For developers, it provides an example of creating a [216].deb
   package, either traditionally or using debhelper, and the version of
   hello used, [217]GNU Hello, serves as an example of writing a [218]GNU
   program.^[219][15]

   Variations of the "Hello, World!" program that produce a [220]graphical
   output (as opposed to text output) have also been shown. [221]Sun
   demonstrated a "Hello, World!" program in [222]Java based on
   [223]scalable vector graphics,^[224][16] and the [225]XL programming
   language features a spinning Earth "Hello, World!" using [226]3D
   computer graphics.^[227][17] Mark Guzdial and [228]Elliot Soloway have
   suggested that the "hello, world" test message may be outdated now that
   graphics and sound can be manipulated as easily as text.^[229][18]

Time to Hello World

   [[230]edit]

   "Time to hello world" (TTHW) is the time it takes to author a "Hello,
   World!" program in a given programming language. This is one measure of
   a programming language's ease of use. Since the program is meant as an
   introduction for people unfamiliar with the language, a more complex
   "Hello, World!" program may indicate that the programming language is
   less approachable.^[231][19] For instance, the first publicly known
   "Hello, World!" program in [232]Malbolge (which actually output "HEllO
   WORld") took two years to be announced, and it was produced not by a
   human but by a code generator written in [233]Common Lisp
   (see [234]§ Variations, above).

   The concept has been extended beyond programming languages to
   [235]APIs, as a measure of how simple it is for a new developer to get
   a basic example working; a shorter time indicates an easier API for
   developers to adopt.^[236][20]^[237][21]
