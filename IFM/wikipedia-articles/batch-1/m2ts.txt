   CAPTION: BDAV MPEG-2 Transport Stream

   [68]Filename extension
   .m2t, .m2ts, .MTS
   [69]Internet media type
   video/MP2T^[70][1]
   Developed by [71]Blu-ray Disc Association
   Initial release August 2004; 20 years ago (2004-08)
   [72]Latest release
   5th edition
   January 2018; 7 years ago (2018-01)
   Type of format [73]Container format

   [74]Container for Audio, video, data
   Contained by [75]Blu-ray Disc, [76]AVCHD
   Extended from [77]MPEG-2 transport stream (ISO/IEC 13818-1)
   [78]Open format? Yes
   [79]Free format? No

   .m2ts is a filename extension used for the Blu-ray disc Audio-Video
   (BDAV) MPEG-2 Transport Stream (M2TS) [80]container [81]file format. It
   is used for [82]multiplexing audio, video and other streams, such as
   subtitles. It is based on the [83]MPEG-2 transport stream
   container.^[84][2]^[85][3]^[86][4]^[87][5] This container format is
   commonly used for [88]high-definition video on [89]Blu-ray Disc and
   [90]AVCHD.^[91][6]

Overview

   [[92]edit]

   The BDAV container format is a [93]modification of the MPEG-2 transport
   stream (ITU-T [94]H.222.0 | [95]ISO/[96]IEC 13818-1) specification for
   random-access media, such as Blu-ray discs, DVDs, hard drives or
   solid-state memory cards. The format is informally called M2TS.

   In order to optimize the storage size, the format uses variable rate
   Transport Streams instead of the constant rates found in MPEG-2 TS
   broadcast. To be able to reconstruct a T-STD compliant constant rate
   Transport Stream for playback, the arrival timestamp of each packet
   needs to be recorded.^[97][7]

   The standard MPEG-2 TS 188-byte packet is prefixed with a 4-byte extra
   header to a total size of 192 bytes. The header consists of a 2-bit
   copy permission indicator and the 30-bit arrival timestamp with a
   resolution of 27 MHz.^[98][8]

   The BDAV container format (.m2ts) is a standard used on Blu-ray
   discs.^[99][9]^[100][10]^[101][11] Blu-ray disc titles authored with
   menu support are in the BDMV (Blu-ray disc Movie) format and contain
   audio, video, and other streams in a BDAV container (.m2ts), which is
   based on the MPEG transport stream format.^[102][4]^[103][5] The BDAV
   container is also used in the BDAV (Blu-ray disc Audio/Visual) disc
   format, the consumer-oriented alternative to the BDMV discs. The BDAV
   disc format is used on [104]BD-RE and BD-R discs for audio/video
   recording.^[105][5]^[106][12]

   The BDAV container with filename extension .MTS or .m2ts is also used
   in [107]AVCHD format, which is a high-definition digital video camera
   recorder format.^[108][13] AVCHD is a simpler form of the Blu-ray disc
   standard with just one video encoding algorithm and two audio
   encodings.^[109][13]^[110][14] Compared to Blu-ray disc format, AVCHD
   can use various storage media, such as [111]DVD media, [112]memory
   cards or [113]hard disk drives. The BDAV container contains videos
   recorded using AVCHD [114]camcorders, such as Sony's HDR-SR(xx) series
   models. Panasonic, Canon and other brands of AVCHD camcorders also
   store recorded video in the BDAV container format.

Formats

   [[115]edit]

   The BDAV container format used on Blu-ray discs can contain one of the
   three mandatory supported [116]video compression
   formats–[117]H.262/MPEG-2 Part 2, [118]H.264/MPEG-4 AVC or [119]SMPTE
   [120]VC-1^[121][15]–and [122]audio compression formats, such as
   [123]Dolby Digital, [124]DTS or uncompressed [125]Linear PCM.
   Optionally supported audio formats are [126]Dolby Digital Plus,
   [127]DTS-HD High Resolution Audio, [128]DTS-HD Master Audio and
   [129]Dolby TrueHD.^[130][11]^[131][16]

   The BDAV container format used on AVCHD equipment is more restricted
   and can contain only H.264/MPEG-4 AVC video compression and Dolby
   Digital (AC-3) audio compression or uncompressed LPCM audio.^[132][14]

File and directory structure

   [[133]edit]

   See also: [134]Blu-ray Disc § Directory and file structure, and
   [135]AVCHD § Overview

   The names of M2TS files are in the form
   zzzzz.m2ts, where zzzzz is a five-digit number corresponding to the
   audiovisual clip. This number is also used in the filename of an
   associated clip information file "zzzzz.clpi".^[136][11] (This number
   can be a [137]date and time stamp of when the video clip was recorded.)
   Each stream has its own file.^[138][17]

   Files in the AVCHD format use the legacy [139]8.3 filename convention,
   whereas Blu-ray discs use [140]long filenames. This is why the filename
   extension of video files is ".MTS" instead of Blu-ray disc's ".m2ts".
   Also, other files use different extensions: .CPI – .clpi, .MPL – .mpls,
   .BDM – .bdmv.^[141][13]^[142][18]^[143][19]

   The M2TS files on a Blu-ray disc are placed in the subdirectory "
   STREAM" of the "BDMV" (or "BDAV") directory, which is at the root
   level. (e.g. \BDMV\STREAM\00001.m2ts or
   \BDAV\STREAM\00001.m2ts)^[144][2]^[145][10] On some AVCHD equipment,
   the "BDMV" directory is located in the "AVCHD" directory, which is
   placed at the root level (e.g. \AVCHD\BDMV\STREAM\00001.MTS).^[146][13]

Software support

   [[147]edit]

   Almost all commercially produced Blu-ray disc titles use a [148]copy
   protection method called the [149]Advanced Access Content System, which
   encrypts the content of the disc, including M2TS files. Software that
   supports M2TS files usually works only with decrypted or unencrypted
   files. Blu-ray disc software players can usually play back encrypted
   content from the original disc. Video content created using AVCHD
   equipment is commonly unencrypted.

   Most M2TS files can be played with [150]ALLPlayer, [151]MPlayer,
   [152]VLC, [153]PotPlayer and other [154]media players, depending on the
   compression formats used in the M2TS file. Some players will need an
   appropriate [155]codec, component or plugin installed.

   Current versions of [156]Nero Vision, [157]FormatFactory,
   [158]MediaCoder, [159]HandBrake and Picture Motion Browser are capable
   of converting M2TS files into [160]MPEG-4 files, which can also be
   viewed using the aforementioned media players.

   M2TS files can also be played on Sony PlayStation 3s, Sony Bravia TVs,
   Western Digital WDTVs, [161]Xtreamer media player, Amkette FlashTV HD
   Media Player and Panasonic Viera TVs supporting playback of AVCHD.

   Apple's [162]Final Cut Pro can read .MTS files (as stored in Sony HDR
   camcorders) by using the AVCHD plugin in the Log and Transfer
   window.^[163][19]
