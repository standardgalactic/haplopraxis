   CAPTION: .at

   [163][220px-Dot-at_domain_logo.png]
   Introduced 20 January 1988
   [164]TLD type [165]Country code top-level domain
   Status Active
   [166]Registry [167]nic.at
   Sponsor [168]nic.at
   Intended use Entities connected with [169]Austria
   Actual use Very popular in Austria, also used for English-language
   [170]domain hacks
   Registered domains 1,468,838 (December 2022)^[171][1]
   Registration restrictions None, except for restricted subdomains .gv.at
   and .ac.at
   Structure Registrations are directly at second level, or at third level
   beneath several second-level labels
   Documents [172]Terms and conditions (English)
   Dispute policies none since October 2008^[173][2]
   [174]DNSSEC yes
   Registry website [175]www.nic.at

   .at is the [176]Internet [177]country code [178]top-level domain
   ([179]ccTLD) for [180]Austria. It is administered by [181]nic.at.

Second-level domains

   [[182]edit]

   The .at top-level domain has a number of [183]second-level domains:
     * .ac.at (reserved for academic institutions, especially
       universities)
     * .gv.at (reserved for the government as well as federal and state
       authorities)
     * .co.at (intended for commercially-oriented companies)
     * .or.at (intended for all kinds of organizations)
     * .priv.at (intended for private Austrian individuals)

   However, it is also possible to register directly at the top level.
   Given the number of [184]English words that end with -at, this presents
   the possibility for many [185]domain hacks.

Known domain hacks

   [[186]edit]

   Many Austrian [187]domain names were registered for [188]English words
   that end with "at". Domain hacks treating "at" as a word in its own
   right (such as arrive.at) are widespread. As of today, there are very
   few such [189]domain names left available on the domain prime market as
   the result of [190]domain name speculation. Most of them can be bought
   on the domain secondary market. Only a few of these [191]domain names
   are actually used. Some known examples of the Austrian [192]domain
   hacks are:
     * donteat.at, a popular [193]Foursquare service
     * many.at, link bundler^[[194]citation needed]
     * hailst.at, official website of [195]Mississippi State Bulldogs
       athletics

Properties

   [[196]edit]

   An .at-Domain can be between one and 63 characters long. Registrations
   of [197]internationalized domain names are accepted.^[198][3] In 2007,
   it was made possible to register domain names containing only numbers.
   The .at-Domain started using [199]DNSSEC in 2011 in order to guarantee
   the authenticity and integrity of the [200]Domain Name System's data.

   Before August 2016, it was only possible to register .at-Domains with
   three or more (two for co.at, ac.at, gv.at, or.at) characters.^[201][4]
