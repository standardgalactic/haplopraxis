   Internet country-code top level domain for Montserrat

   CAPTION: .ms

   [137][Dot-MS_domain_logo.png]
   Introduced 6 March 1997
   [138]TLD type [139]Country code top-level domain
   Status Active
   [140]Registry [141]MNI Networks Ltd
   Sponsor [142]Lubimal (MS) Ltd.
   Intended use Entities connected with [143]Montserrat
   Actual use Used by a number of sites, a few of which are in Montserrat;
   occasionally used by [144]Microsoft for link shortening
   Registration restrictions None
   Structure Registrations are available directly at second level
   Documents [145]Policies
   Dispute policies [146]Complaint Policy & Procedures
   [147]Complaint Resolution Service
   Registry website [148]mninet.ms
   [149]nic.ms

   .ms is the Internet [150]country code [151]top-level domain
   ([152]ccTLD) for [153]Montserrat, a [154]British Overseas
   Territory.^[155][1]

Usage examples

   [[156]edit]
     * [157]Microsoft uses this as an abbreviation for projects such as
       ch9.ms or [158]1drv.ms for its [159]OneDrive. In particular, aka.ms
       is used extensively as a [160]URL shortener for Microsoft's web
       sites, such as [161]http://aka.ms/MFAsetup.
     * Websites based in, or having to do with, the U.S. state of
       [162]Mississippi also use the .ms domain^[163][2] as MS is the
       [164]ISO 3166-2:US code and official [165]United States Postal
       Service abbreviation for the state.
     * Some companies based in the Brazilian state of [166]Mato Grosso do
       Sul ([167]officially abbreviated as MS) use the .ms TLD
     * Some companies and organisations in the [168]German town
       [169]Münster in Westphalia use the TLD as well since MS is the
       [170]official vehicle license plate code for the city.
     * [171]The New York Times uses .ms as a top level domain name for
       [172]permalinks referring to New York Times addresses. For example,
       [173]http://nyti.ms/ reaches The New York Times homepage.
     * The [174]Hillary Clinton [175]2016 presidential campaign used the
       domain name "HRC.ms" as a URL shortener.
     * The family of F1 driver [176]Michael Schumacher used the domain
       name keepfighting.ms for his foundation, established after his
       skiing accident in [177]Méribel on 29 December 2013
     * A [178]Dutch foundation for the cure of [179]multiple sclerosis
       (MS) uses arenamoves.ms.
     * The [180]Dutch organisation openbsd.amsterdam uses obsda.ms for its
       short code link.
