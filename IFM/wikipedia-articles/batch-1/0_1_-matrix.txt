   From Wikipedia, the free encyclopedia
   (Redirected from [82](0,1)-matrix)
   Matrix of binary truth values

   A logical matrix, binary matrix, relation matrix, Boolean matrix, or
   (0, 1)-matrix is a [83]matrix with entries from the [84]Boolean domain
   B = {0, 1}. Such a matrix can be used to represent a [85]binary
   relation between a pair of [86]finite sets. It is an important tool in
   [87]combinatorial mathematics and [88]theoretical computer science.

Matrix representation of a relation

   [[89]edit]

   If R is a [90]binary relation between the finite [91]indexed sets X and
   Y (so R ⊆ X ×Y), then R can be represented by the logical matrix M
   whose row and column indices index the elements of X and Y,

   sets X and Y are indexed with positive [92]integers: i ranges from 1 to
   the [93]cardinality (size) of X, and j ranges from 1 to the cardinality
   of Y. See the article on [94]indexed sets for more detail.

Example

   [[95]edit]

   The binary relation R on the set {1, 2, 3, 4} is defined so that aRb
   holds if and only if a [96]divides b evenly, with no remainder. For
   example, 2R4 holds because 2 divides 4 without leaving a remainder, but
   3R4 does not hold because when 3 divides 4, there is a remainder of 1.
   The following set is the set of pairs for which the relation R holds.

          {(1, 1), (1, 2), (1, 3), (1, 4), (2, 2), (2, 4), (3, 3), (4,
          4)}.

   The corresponding representation as a logical matrix is

Other examples

   [[97]edit]
     * A [98]permutation matrix is a (0, 1)-matrix, all of whose columns
       and rows each have exactly one nonzero element.
          + A [99]Costas array is a special case of a permutation matrix.
     * An [100]incidence matrix in [101]combinatorics and [102]finite
       geometry has ones to indicate incidence between points (or
       vertices) and lines of a geometry, blocks of a [103]block design,
       or edges of a [104]graph.
     * A [105]design matrix in [106]analysis of variance is a (0,
       1)-matrix with constant row sums.
     * A logical matrix may represent an [107]adjacency matrix in
       [108]graph theory: non-[109]symmetric matrices correspond to
       [110]directed graphs, symmetric matrices to ordinary [111]graphs,
       and a 1 on the diagonal corresponds to a [112]loop at the
       corresponding vertex.
     * The [113]biadjacency matrix of a simple, undirected [114]bipartite
       graph is a (0, 1)-matrix, and any (0, 1)-matrix arises in this way.
     * The [115]prime factors of a list of m [116]square-free,
       [117]n-smooth numbers can be described as an m × π(n) (0,
       1)-matrix, where π is the [118]prime-counting function, and a[ij]
       is 1 if and only if the jth prime divides the ith number. This
       representation is useful in the [119]quadratic sieve factoring
       algorithm.
     * A [120]bitmap image containing [121]pixels in only two colors can
       be represented as a (0, 1)-matrix in which the zeros represent
       pixels of one color and the ones represent pixels of the other
       color.
     * A binary matrix can be used to check the game rules in the game of
       [122]Go.^[123][1]
     * The [124]four valued logic of two bits, transformed by 2x2 logical
       matrices, forms a [125]transition system.
     * A [126]recurrence plot and its variants are matrices that shows
       which pairs of points are closer than a certain vicinity threshold
       in a [127]phase space.

Some properties

   [[128]edit]
   [129][220px-Matrix_multiply.png] Multiplication of two logical matrices
   using [130]Boolean algebra.

   The matrix representation of the [131]equality relation on a finite set
   is the [132]identity matrix I, that is, the matrix whose entries on the
   diagonal are all 1, while the others are all 0. More generally, if
   relation R satisfies I ⊆ R, then R is a [133]reflexive relation.

   If the Boolean domain is viewed as a [134]semiring, where addition
   corresponds to [135]logical OR and multiplication to [136]logical AND,
   the matrix representation of the [137]composition of two relations is
   equal to the [138]matrix product of the matrix representations of these
   relations. This product can be computed in [139]expected time
   O(n^2).^[140][2]

   Frequently, operations on binary matrices are defined in terms of
   [141]modular arithmetic mod 2—that is, the elements are treated as
   elements of the [142]Galois field
   [MATH: <semantics> <mrow class="MJX-TeXAtom-ORD"> <mstyle
   displaystyle="true" scriptlevel="0"> <mrow class="MJX-TeXAtom-ORD">
   <mrow class="MJX-TeXAtom-ORD"> <mi mathvariant="bold">G</mi> <mi
   mathvariant="bold">F</mi> </mrow> </mrow> <mo stretchy="false">(</mo>
   <mn>2</mn> <mo stretchy="false">)</mo> <mo>=</mo> <msub> <mrow
   class="MJX-TeXAtom-ORD"> <mi mathvariant="double-struck">Z</mi> </mrow>
   <mrow class="MJX-TeXAtom-ORD"> <mn>2</mn> </mrow> </msub> </mstyle>
   </mrow> <annotation encoding="application/x-tex">{\displaystyle
   {\mathbf {GF}}(2)=\mathbb {Z} _{2}}</annotation> </semantics> :MATH]
   {\displaystyle {\mathbf {GF}}(2)=\mathbb {Z} _{2}} . They arise in a
   variety of representations and have a number of more restricted special
   forms. They are applied e.g. in [143]XOR-satisfiability.

   The number of distinct m-by-n binary matrices is equal to 2^mn, and is
   thus finite.

   a logical matrix is obtained by swapping all zeros and ones for their
   opposite.

   A is a logical matrix with no columns or rows identically zero. Then
   the matrix product, using Boolean arithmetic,

   As a mathematical structure, the Boolean algebra U forms a [150]lattice
   ordered by [151]inclusion; additionally it is a multiplicative lattice
   due to matrix multiplication.

   Every logical matrix in U corresponds to a binary relation. These
   listed operations on U, and ordering, correspond to a [152]calculus of
   relations, where the matrix multiplication represents [153]composition
   of relations.^[154][3]

Row and column sums

   [[193]edit]

   Adding up all the ones in a logical matrix may be accomplished in two
   ways: first summing the rows or first summing the columns. When the row
   sums are added, the sum is the same as when the column sums are added.
   In [194]incidence geometry, the matrix is interpreted as an
   [195]incidence matrix with the rows corresponding to "points" and the
   columns as "blocks" (generalizing lines made of points). A row sum is
   called its point degree, and a column sum is the block degree. The sum
   of point degrees equals the sum of block degrees.^[196][5]

   An early problem in the area was "to find necessary and sufficient
   conditions for the existence of an [197]incidence structure with given
   point degrees and block degrees; or in matrix language, for the
   existence of a (0, 1)-matrix of type v × b with given row and column
   sums".^[198][5] This problem is solved by the [199]Gale–Ryser theorem.
