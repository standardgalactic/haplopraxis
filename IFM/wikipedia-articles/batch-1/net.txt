   The .NET platform (pronounced as "dot net") is a partially open source
   with patent encumbered technology, [116]managed computer [117]software
   framework for [118]Windows, [119]Linux, and [120]macOS [121]operating
   systems.^[122][4] The project is mainly developed by [123]Microsoft
   employees by way of the [124].NET Foundation and is released under an
   [125]MIT License.^[126][3]

   New versions of the .NET platform are released annually, typically in
   November. The most recent version of .NET is .NET 9, released in
   November 2024, while the current long-term support (LTS) version is
   .NET 8, released in November 2023 and scheduled to receive updates
   until November 2026.

History

   [[127]edit]

   See also: [128]C Sharp (programming language) § History, and [129].NET
   Framework § History

   In the late 1990s, Microsoft began developing a [130]managed code
   runtime and programming language ([131]C#) which it billed together as
   part of the ".NET platform", with the core runtime and [132]software
   libraries comprising the [133].NET Framework.

     At the heart of the .NET Platform is the .NET Framework, a
     high-productivity, multilanguage development and execution
     environment for building and running Web services with important
     features such as cross-language inheritance and debugging.^[134][5]

   Soon after the announcement of the C# language at the [135]Professional
   Developers Conference in 2000 and previews of its software became
   available, Microsoft began a standardization effort through [136]ECMA
   for what it dubbed the [137]Common Language Infrastructure. The company
   continued development and support of its own implementation as
   [138]proprietary, closed source software in the meantime.

   On November 12, 2014, Microsoft introduced .NET Core—an open-source,
   [139]cross-platform^[140][6] successor^[141][7] to [142].NET
   Framework—and released [143]source code for the .NET Core [144]CoreCLR
   implementation, source for the "entire [...] library stack" for .NET
   Core,^[145][8] and announced the adoption of a conventional
   ([146]"bazaar"-like) [147]open-source development model under the
   stewardship of the [148].NET Foundation. [149]Miguel de Icaza describes
   .NET Core as a "redesigned version of .NET that is based on the
   simplified version of the class libraries",^[150][9] and Microsoft's
   Immo Landwerth explained that .NET Core would be "the foundation of all
   future .NET platforms". At the time of the announcement, the initial
   release of the .NET Core project had been seeded with a subset of the
   libraries' source code and coincided with the relicensing of
   Microsoft's existing .NET reference source away from the restrictions
   of the [151]Ms-RSL. Landwerth acknowledged the disadvantages of the
   formerly selected shared license, explaining that it made [152]codename
   Rotor "a non-starter" as a community-developed open source project
   because it did not meet the criteria of an [153]Open Source Initiative
   (OSI) approved license.^[154][10]^[155][11]^[156][12]

   .NET Core 1.0 was released on June 27, 2016,^[157][13] along with
   [158]Microsoft Visual Studio 2015 Update 3, which enables .NET Core
   development.^[159][14] .NET Core 1.0.4 and .NET Core 1.1.1 were
   released along with .NET Core Tools 1.0 and Visual Studio 2017 on March
   7, 2017.^[160][15]

   .NET Core 2.0 was released on August 14, 2017, along with Visual Studio
   2017 15.3, ASP.NET Core 2.0, and [161]Entity Framework Core
   2.0.^[162][16] .NET Core 2.1 was released on May 30, 2018.^[163][17]
   NET Core 2.2 was released on December 4, 2018.^[164][18]

   .NET Core 3 was released on September 23, 2019.^[165][19] NET Core 3
   adds support for Windows desktop application development^[166][20] and
   significant performance improvements throughout the base library.

   In November 2020, Microsoft released .NET 5.0.^[167][21] The "Core"
   branding was abandoned and version 4.0 was skipped to avoid conflation
   with .NET Framework, of which the latest releases had all used 4.x
   [168]versioning for all significant (non-bugfix) releases since 2010.

   It addresses the patent concerns related to the .NET Framework
   ^[[169]citation needed].

   In November 2021, Microsoft released .NET 6.0,^[170][22] in November
   2022 released .NET 7.0,^[171][23] in November 2023 released .NET
   8.0,^[172][24] and in November 2024 released .NET 9.0.^[173][25]

Language support

   [[203]edit]

   [204][280px-Overview_of_the_Common_Language_Infrastructure_2015.svg.png
   ] .NET uses the [205]Common Language Infrastructure (CLI).

   .NET fully supports [206]C# and [207]F# (and [208]C++/CLI as of 3.1;
   only enabled on Windows) and supports [209]Visual Basic .NET (for
   version 15.5 in .NET Core 5.0.100-preview.4, and some old versions
   supported in old .NET Core).^[210][35]

   VB.NET compiles and runs on .NET, but as of .NET Core 3.1, the separate
   Visual Basic Runtime is not implemented. Microsoft initially announced
   that .NET Core 3 would include the Visual Basic Runtime, but after two
   years the timeline for such support was updated to .NET
   5.^[211][36]^[212][37]

Architecture

   [[213]edit]

   Main article: [214]Common Language Infrastructure

   .NET supports the following [215]cross-platform scenarios: [216]ASP.NET
   Core [217]web apps, command-line/console apps, libraries and
   [218]Universal Windows Platform apps. Prior to .NET Core 3.0, it did
   not implement [219]Windows Forms or [220]Windows Presentation
   Foundation (WPF), which render the standard [221]GUI for desktop
   software on Windows.^[222][38] However, from .NET Core 3 on, it started
   implementing them along with [223]Universal Windows Platform
   (UWP).^[224][39] It is also possible to write cross-platform graphical
   applications using .NET with the [225]GTK# language-binding for the
   [226]GTK widget toolkit.

   .NET supports use of [227]NuGet packages. Unlike [228].NET Framework,
   which is serviced using [229]Windows Update, .NET used to rely on its
   [230]package manager to receive updates.^[231][38] Since December 2020,
   however, .NET updates started being delivered via Windows Update as
   well.^[232][40]

   The two main components of .NET are CoreCLR and CoreFX, which are
   comparable to the [233]Common Language Runtime (CLR) and the
   [234]Framework Class Library (FCL) of the [235].NET Framework's
   [236]Common Language Infrastructure (CLI) implementation.^[237][41]

   As an implementation of CLI's [238]Virtual Execution System (VES),
   CoreCLR is a complete [239]runtime and [240]virtual machine for
   [241]managed [242]execution of CLI programs and includes a
   [243]just-in-time compiler called RyuJIT.^[244][42]^[245][a] .NET Core
   also contains CoreRT, the .NET Native runtime optimized to be
   integrated into [246]AOT compiled native [247]binaries.^[248][44]

   As an implementation of CLI's [249]Standard Libraries,^[250][45] CoreFX
   shares a subset of .NET Framework APIs, however, it also comes with its
   own APIs that are not part of the .NET Framework.^[251][38] A variant
   of the .NET [252]library is used for [253]UWP.^[254][46]

   The .NET [255]command-line interface offers an execution entry point
   for [256]operating systems and provides developer services like
   compilation and package management.^[257][47]
   [258][220px-UML_dotnet_streams.svg.png] UML package diagram of the
   stream hierarchy in .NET

.NET MAUI

   [[259]edit]

   .NET Multi-platform App UI (.NET MAUI, introduced with .NET 6) is a
   cross-platform framework for creating native mobile and desktop apps
   with [260]C# and [261]Extensible Application Markup Language
   (XAML),^[262][48] which also supports [263]Android and [264]iOS.

Mascot

   [[265]edit]

   [266][150px-Dotnet-bot.svg.png] dotnet bot, the community mascot for
   .NET

   The official community mascot of .NET is the .NET Bot (stylized as
   "dotnet bot" or "dotnet-bot"). The dotnet bot served as the placeholder
   developer for the initial check-in of the .NET source code when it was
   open-sourced.^[267][49] It has since been used as the official mascot.
