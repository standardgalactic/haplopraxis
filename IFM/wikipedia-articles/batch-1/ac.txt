   Country code top-level domain for Ascension Island
   This article is about the country code top-level domain. For the
   second-level domain, see [156].ac (second-level domain).

   CAPTION: .ac

   [157][.ac_ccTLD_logo.png]
   Introduced December 19, 1997; 27 years ago (1997-12-19)
   [158]TLD type [159]Country code top-level domain
   Status Active
   [160]Registry [161]Ascension Island Network Information Centre (run by
   [162]Internet Computer Bureau)
   Sponsor [163]Sure
   Intended use Entities connected with [164]Ascension Island
   Actual use Various uses, sometimes connected to education and academia;
   a few sites actually on Ascension Island
   Registration restrictions 3rd level registrant must be resident on
   Ascension Island
   Structure Registrations are taken directly at the second level or at
   third level beneath various 2nd-level labels
   Documents [165]Terms & Conditions; [166]Rules
   Dispute policies [167]Dispute Resolution Policy
   [168]DNSSEC Yes
   Registry website [169]nic.ac

   The .ac [170]top-level domain is the [171]Internet [172]country code
   ([173]ccTLD) for [174]Saint Helena, Ascension and Tristan da Cunha,
   used primarily for [175]Ascension Island ([176]Saint Helena has its own
   ccTLD, [177].sh). It is administered by NIC.AC, a subsidiary of the
   [178]Afilias-owned company [179]Internet Computer Bureau.

   Registration for the domain is open to anyone. The registry accepts
   registrations of [180]internationalized domain names.^[181][1]
